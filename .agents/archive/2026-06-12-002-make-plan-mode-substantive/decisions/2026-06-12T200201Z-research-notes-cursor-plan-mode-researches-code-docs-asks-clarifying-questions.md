# Decision: Research notes: Cursor plan mode researches code/docs, asks clarifying questions

Status: proposed
By: smart

Research notes: Cursor plan mode researches code/docs, asks clarifying questions, produces editable Markdown with file paths/todos, and can save to workspace. Claude Code plan mode is read-only until approval and exits through a plan approval tool with optional requested Bash permissions. IBM agent-planning guidance emphasizes decomposition, reflection, tool use, logging, interruptibility, and human supervision. Codex CLI exposes noninteractive exec/review and read-only sandboxing rather than a direct plan subcommand in help.
