# Decision: UI revamp follow-up plan: build a CLI-first role view that treats Agents lifecyc

Status: proposed
By: smart

UI revamp follow-up plan: build a CLI-first role view that treats Agents lifecycle events as the source of truth, adds explicit role sections for coordinator/implementer/reviewer, supports structured agent progress directives or task-status updates for in-progress display, keeps raw provider stdout/stderr in run logs, exposes log drill-down only on demand, and preserves scriptable output for non-interactive commands.
